PHOTOMACHINE · SQUARE FIRST EDITION

COMO ABRIR
1. Mantenha o index.html, styles.css, app.js e a pasta assets juntos.
2. Abra o index.html no Chrome, Edge ou Firefox.
3. Role a página livremente ou use o menu para navegar pelas áreas principais.
4. Explore as demonstrações de seleção, edição, aprovação e cenário operacional.

IMPORTANTE
- A página é estática e funciona sem servidor ou etapa de compilação.
- A experiência principal funciona sem internet e sem dependências externas.
- O JavaScript adiciona interações; todo o conteúdo permanece legível sem ele.

DEPLOY
- O render.yaml configura o projeto como Static Site no Render.
- Commits na branch main disparam deploy automático após o Blueprint ser conectado.
- Pull Requests podem gerar previews para revisão antes do merge.
